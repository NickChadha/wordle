This is my implementation of a Wordle clone game. My general approach to the project was to start with the most core functionality first then add on with the visual elements and advanced functionality after. 
I started with the initializegame function to set myself up at a blank slate condition of the game. 
After this, and after every major function I implemented, I ran the index.html file to ensure that the function I added worked as intended. 
Many times I ran into issues with my code not working as I intended because it wasn't reaching certain functions, so I debugged by added showMessage() functions at different points in the problem code to see where the issue occurred. 
I was able to work through the handlekey function and submit guess function quite well and I kept making my way toward to more intricate functions in the code until I managed to test my Wordle clone and not encounter any problems. I cleaned up the code after this and it was in a good state to submit.
